Подробный гайд

  1. Создай репозиторий на GitHub (публичный). Например vasay-status.
  2. Залей файл status.json в корень (или в папку). Содержимое по умолчанию: 
    {
  "instant": true,
  "studio120": true,
  "message": "",
  "updated": "2026-10-09T00:00:00Z"
}
  3. Скопируй raw-ссылку: открой файл на GitHub → кнопка Raw → скопируй URL вида
    https://raw.githubusercontent.com/ТВОЙ_ЛОГИН/vasay-status/main/status.json
  4. В расширении открой панель → вкладка Misc → вставь URL в поле Status URL → Save URL · Check now. Бейдж станет LIVE.
  5. Чтобы выключить для всех: на этой странице нажми красную кнопку → скачается status.json → на GitHub замени файл (Upload / Edit) → Commit changes.
  6. В течение ~20 секунд у всех, у кого прописан этот URL, Process по отключённому методу выдаст ошибку в логе.
  7. Включить обратно: кнопка «Включить всё» → снова Commit того JSON на GitHub.

Сеть недоступна → расширение не блокирует (fail-open). URL с YOUR_USER не задан → методы работают, бейдж показывает «URL not set».
