🎬 Auto convert for TikTok (CompressBase)

Revance uses public metadata when the API allows. Short links are expanded. Profile stats for @urfair.aep load from the same public sources. No invented shadowban scores.

📖 What Revance can (and cannot) do

CanExpand vm.tiktok.com / vt.tiktok.com short links
CanUsername, video ID, caption, author, thumbnail
CanPublic likes/comments when present in share metadata
CanPublished date & language signals when available
CannotDetect shadowban (private to TikTok)
CannotKnow exact upload country from the public link
CannotMeasure real bitrate / resolution without the media file

How the fetch works

1. Validate TikTok URL (full or short).
2. Call Microlink (CORS-friendly) — expands short links and returns public share metadata.
3. Try TikTok oEmbed on the expanded URL for extra fields.
4. Show only real fields; never invent shadowban % or fake counters.
